# 🔥 Forest Fire Prediction using Machine Learning

A Machine Learning project that predicts the burned area of forest fires using environmental and weather-related data.

## 📌 Project Overview

This project analyzes forest fire data and builds regression models to predict the burned area based on environmental conditions.

The project compares Linear Regression and Random Forest Regression to evaluate their prediction performance.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Project Workflow

1. Load and explore the forest fire dataset.
2. Analyze the distribution of burned areas.
3. Apply log transformation to the target variable.
4. Encode categorical features.
5. Scale the input features.
6. Split the dataset into training and testing sets.
7. Train Linear Regression and Random Forest models.
8. Evaluate model performance using R² Score and Mean Absolute Error.
9. Visualize predictions and feature importance.

## 🤖 Machine Learning Models

- Linear Regression
- Random Forest Regression
